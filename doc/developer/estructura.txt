--------------------------------------------------------------------------------
 1. PUNTOS DE ENTRADA (cmd/) — por aquí se entra al programa
--------------------------------------------------------------------------------
  cmd/server/main.go     → erpgow.exe. Parsea flags (--setup, --migrate,
                           --install, --uninstall), carga config, prepara BD
                           y levanta HTTP + gRPC.
  cmd/server/fieldkey.go → resolución de claves de campos.
  cmd/docgen/            → genera el manual doc/developer/index2.html.
  cmd/diag/              → diagnóstico de entorno.
  cmd/genhash/           → generación de hashes.
  cmd/semillar/          → siembra datos de prueba.

  Cadena de arranque:
    flags → configs.EnsureEnv() → logger.Init() → infrastructure/persistence
          → interfaces/web.NewServer() [HTTP] + internal/pos [gRPC]
          → erpApplication.Start() → Ctrl+C apaga en orden (gRPC → HTTP → BD)

--------------------------------------------------------------------------------
 2. CAPA DE PRESENTACIÓN (interfaces/web/) — la mayor parte del código
--------------------------------------------------------------------------------
  ~170 archivos .go. Aquí vive todo lo que responde al navegador:

    server.go             → NewServer(): mux, rutas, estáticos, middleware.
    session.go            → almacén de sesiones (persistente en BD de control).
    permissions.go        → roles y permisos.
    render.go / cache.go  → pintado de plantillas con caché.
    audit_chain.go        → cadena de auditoría.
    tenants.go            → multi-empresa (aislamiento por tenant).
    pos_api.go / pos_admin.go / pos_sync.go / pos_auth.go → API REST del POS.
    ai_*.go               → agentes, proveedores, herramientas y reportes IA.
    product.go / purchase.go / quotation.go / payroll.go / bank.go /
    cartera.go / period_close.go … → módulos de negocio.

  Middlewares (en orden): cacheDefaultMiddleware → corsMiddleware
                          → authMiddleware (attachScope + sesión + CSRF)

--------------------------------------------------------------------------------
 3. LÓGICA DE NEGOCIO Y SERVICIOS (internal/)
--------------------------------------------------------------------------------
  internal/orchestrator/   LA PUERTA ÚNICA DE ESCRITURAS.
                           journal.go + orchestrator.go: valida identificadores,
                           escribe primero en journal, encola, UN SOLO escritor
                           aplica en orden con correlativo e idempotencia, y
                           deja rastro en audit_log. Así no se pierden ventas.

  internal/queue/          Cola de tareas en segundo plano con pool fijo,
                           backpressure y volcado a disco.

  internal/pos/            Servidor gRPC de las cajas POS (puerto 9095):
                           grpc_server.go, server.go, sync_server.go, ai.go.

  internal/logger/         Logging por niveles (LOG_ENABLED/LOG_LEVEL/LOG_FILE).
  internal/service/        Instalación como servicio de Windows (SCM).
  internal/setup/          Wizard de instalación (--setup): MariaDB, puertos,
                           super admin y roles base.
  internal/security/       Cifrado/descifrado de datos sensibles.
  internal/upload/         Subida segura de archivos.
  internal/webcheck/       Verificación de salud web.

 5. CONTRATO GRPC DEL POS (proto/)
--------------------------------------------------------------------------------
  proto/pos.proto          → define POSService: Connect (stream bidireccional),
                             Login, OpenTurn, CloseTurn, ProcessSale,

  proto/pos/pos.pb.go      → mensajes generados por protoc.
  proto/pos/pos_grpc.pb.go → stubs de cliente/servidor generados.

 6. MIGRACIONES (migrations/)

12. CÓMO EJECUTAR
--------------------------------------------------------------------------------
  Compilar ................ go build -o erpgow.exe ./cmd/server
  Desarrollo .............. go run ./cmd/server   (o iniciar.bat)
  Asistente ............... erpgow.exe --setup
  Migraciones ............. erpgow.exe --migrate
  Servicio Windows ........ erpgow.exe --install  →  net start
  Tests rápidos ........... go vet ./...  ·  go test -short ./...
  Tests completos ......... go test ./...  (requiere MySQL)
  Regenerar index2.html ... go run ./cmd/docgen
  Reconstruir este índice . node doc/developer/_build.mjs
