Visión y Propósito del ProyectoEl Objetivo Social: Aportar valor real al comercio y emprendedores venezolanos (ej. programa 1.000 Empresas de Polar) entregando un "tanque de guerra" contable y fiscal sin costo de licencias.   La Filosofía Comercial: El software se entrega como Freeware B2B (binario ejecutable de uso libre) bajo la propiedad de Orcanet1724 C.A..   Monetización Sostenible: Se factura por servicios de valor agregado: hosting VPS/Cloud, desarrollos de módulos a la medida, soporte técnico dedicado y suscripciones a asistentes de IA.   2. Mecánica de Carga de Módulos (Addons)Detección y Firma Digital: Al arrancar, erpgow.exe escanea la carpeta /addons. Valida que el sub-binario contenga la firma criptográfica (Ed25519 / RSA) de Orcanet1724 C.A. y la vinculación con la licencia del cliente (RIF).   Ejecución Asilada (Proceso Hijo): Si la firma es válida, el core ejecuta el sub-binario en segundo plano. La comunicación entre el Core y el Módulo se realiza a milisegundos mediante gRPC o Sockets IPC locales.Inyección Dinámica de Interfaz: El módulo extrae/sirve sus archivos de TypeScript, CSS y plantillas en un subdirectorio aislado y registra sus rutas/submenús en la tabla sub_module para actualizar el menú lateral de la interfaz.Respeto a la Cadena Inmutable (SHA-256): Ningún módulo escribe directamente en la auditoría fiscal. El módulo solicita la transacción al Core, y este es el único notario que calcula el hash encadenado (audit_chain) y persiste en la base de datos.   3. Modelo de Licenciamiento y Seguridad CriptográficaPara evitar el uso no autorizado de módulos de pago o la proliferación de versiones adulteradas que comprometan el cumplimiento fiscal:   Licencia Única por Comercio: Aunque el binario sea gratuito, cada usuario registra sus datos (RIF y Razón Social) para recibir una clave de licencia única emitida por Orcanet.   Firmas Cruzadas para Addons: Un módulo descargado del Marketplace se empaqueta firmado específicamente para el RIF del cliente:$$\text{Firma} = \text{Sign}_{\text{Orcanet}}(\text{RIF\_Cliente} + \text{ID\_Licencia} + \text{ID\_Modulo})$$Si alguien intenta copiar el ejecutable del módulo a otro negocio con RIF distinto, el Core de ERPGo rechazará la ejecución.Protección de Código: Los ejecutables en Go van compilados y ofuscados, garantizando la seguridad del desarrollo sin perder velocidad de respuesta.4. Garantía de Permanencia (Cláusula de Continuidad)Para destruir el miedo al "secuestro de datos" por parte de casas de software tradicionales:   Uso Libre Irrevocable: El contrato de licencia otorga el uso perpetuo y gratuito de la versión freeware del binario para la empresa registrada.   Cláusula Open Source a 20 Años / Fuerza Mayor: En los términos de servicio se establece que el código fuente pasará automáticamente a licencias de Código Abierto (Open Source) si transcurren 20 años o si ocurre cese permanente de operaciones de la empresa titular. La base de datos (SQLite/MySQL) y la información siempre son propiedad del usuario.   5.
