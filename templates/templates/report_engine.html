Guía para crear informes personalizados

1. Estructura básica
{
  "title": "Ventas por cliente",
  "sql": "SELECT c.customer_name AS cliente, SUM(i.total_amount) AS total FROM invoice i JOIN customer_information c ON c.customer_id = i.customer_id GROUP BY c.customer_name",
  "columns": [
    {"key": "cliente", "label": "Cliente"},
    {"key": "total", "label": "Total"}
  ],
  "totals": ["total"],
  "params": [
    {"name":"desde","label":"Desde","type":"date","required":true},
    {"name":"hasta","label":"Hasta","type":"date","required":true}
  ]
}
2. Con gráfico

Agregue un bloque "chart" al JSON:

{
  "title": "Ventas por mes",
  "sql": "SELECT DATE_FORMAT(i.date,'%Y-%m') AS mes, SUM(i.total_amount) AS total FROM invoice i GROUP BY mes ORDER BY mes",
  "columns": [
    {"key": "mes", "label": "Mes"},
    {"key": "total", "label": "Total"}
  ],
  "totals": ["total"],
  "chart": {
    "type": "line",
    "x_key": "mes",
    "y_key": "total",
    "y_label": "Ventas (Bs)",
    "title": "Ventas por mes"
  }
}
3. Tipos de gráfico: line, bar, pie, doughnut
4. Reglas de seguridad
  • Solo SELECT — El sistema bloquea cualquier instrucción de escritura, por prompt o por inyección.
  • Tablas fiscales (acc_transaction, acc_vaucher, audit_log) son de solo lectura para informes.
  • Datos de alto perfil — los informes que tocan costos, márgenes o sueldos se registran en auditoría; el administrador puede restringirlos.
  • Informes fiscales (retenciones IVA/ISLR, IGTF) no pueden ser alterados ni por humanos ni por IA.
