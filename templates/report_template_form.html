Guía para crear informes personalizados

1. Estructura básica (sin gráfico)
{
  "title": "Ventas por cliente",
  "sql": "SELECT c.customer_name AS cliente, SUM(i.total_amount) AS total FROM invoice i JOIN customer_information c ON c.customer_id = i.customer_id WHERE i.date BETWEEN :desde AND :hasta GROUP BY c.customer_name",
  "columns": [
    {"key": "cliente", "label": "Cliente"},
    {"key": "total", "label": "Total"}
  ],
  "totals": ["total"],
  "params": [
    {"name":"desde","label":"Desde","type":"date","required":true},
    {"name":"hasta","label":"Hasta","type":"date","required":true}
  ]
}
2. Con gráfico

Agregue un bloque "chart" al JSON:

{
  "title": "Ventas por mes",
  "sql": "SELECT DATE_FORMAT(i.date,'%Y-%m') AS mes, SUM(i.total_amount) AS total FROM invoice i GROUP BY mes ORDER BY mes",
  "columns": [
    {"key": "mes", "label": "Mes"},
    {"key": "total", "label": "Total"}
  ],
  "totals": ["total"],
  "chart": {
    "type": "line",
    "x_key": "mes",
    "y_key": "total",
    "y_label": "Ventas (Bs)",
    "title": "Ventas por mes"
  }
}
3. Tipos de gráfico
  • line — Línea temporal
  • bar — Barras verticales
  • pie — Pastel (proporciones)
  • doughnut — Dona
4. Reglas de seguridad (Nivel 1)
  • Solo SELECT — El sistema bloquea INSERT, UPDATE, DELETE, DROP, ALTER, etc. Ningún SQL de escritura funciona, aunque lo fuerce por prompt.
  • Tablas fiscales protegidas — Las tablas acc_transaction, acc_vaucher, audit_log son de solo lectura para informes. No pueden alterarse.
  • Informes de datos delicados (costos, márgenes, sueldos, retenciones): un usuario sin rol gerencial puede generarlos pero se registran en auditoría. El administrador puede desactivar informes sensibles.
  • Plantillas creadas por IA pasan por el mismo guardián que las humanas — el agente no puede saltarse las reglas.
  • Períodos cerrados — El informe muestra una advertencia si apunta a un período contable cerrado.
5. Parámetros disponibles
  • type: "date" — Fecha (formato AAAA-MM-DD)
  • type: "number" — Número
  • type: "text" — Texto libre
  • type: "enum" — Lista desplegable (requiere "options":[...])

Use "required": true para campos obligatorios.
