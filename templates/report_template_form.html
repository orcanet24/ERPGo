Guía para crear informes personalizados

1. Estructura básica (sin gráfico)
{
  "title": "Ventas por cliente",
  "sql": "SELECT c.customer_name AS cliente, SUM(i.total_amount) AS total FROM invoice i JOIN customer_information c ON c.customer_id = i.customer_id WHERE i.date BETWEEN :desde AND :hasta GROUP BY c.customer_name",
  "columns": [
    {"key": "cliente", "label": "Cliente"},
    {"key": "total", "label": "Total"}
  ],
  "totals": ["total"],
  "params": [
    {"name":"desde","label":"Desde","type":"date","required":true},
    {"name":"hasta","label":"Hasta","type":"date","required":true}
  ]
}
2. Con gráfico

Agregue un bloque "chart" al JSON:

{
  "title": "Ventas por mes",
  "sql": "SELECT DATE_FORMAT(i.date,'%Y-%m') AS mes, SUM(i.total_amount) AS total FROM invoice i GROUP BY mes ORDER BY mes",
  "columns": [
    {"key": "mes", "label": "Mes"},
    {"key": "total", "label": "Total"}
  ],
  "totals": ["total"],
  "chart": {
    "type": "line",
    "x_key": "mes",
    "y_key": "total",
    "y_label": "Ventas (Bs)",
    "title": "Ventas por mes"
  }
}
3. Tipos de gráfico soportados
  • line — Línea temporal
  • bar — Barras verticales
  • pie — Pastel (proporciones)
  • doughnut — Dona
Reglas de seguridad (Nivel 1)
  • Solo SELECT — El sistema bloquea INSERT, UPDATE, DELETE, DROP, ALTER.
  • Tablas fiscales protegidas — Las tablas acc_transaction, acc_vaucher, audit_log son de solo lectura.
  • Auditoría activa — Informes sensibles quedan registrados.
  • Guardianes IA — Las plantillas generadas por IA respetan estas reglas sin excepción.
Asistente de IA: Generación y Vista Previa Interactiva
1. Describe el informe
2. Definición JSON (editable manualmente)
3. Vista previa (Ejecución real)

Genera la definición para cargar los datos reales del informe.

Ajustar informe con IA
La IA aplicará este cambio sobre la definición actual.
Finalizar y Guardar Informe
