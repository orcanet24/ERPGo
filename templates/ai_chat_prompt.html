Instrucciones de uso

  • Primero active o cree un proveedor en la página de Configuración IA.
  • Cada proveedor (OpenAI, OpenRouter, Groq, DeepSeek, Ollama local, ...) usa su propia API key.
  • Incluya tipos de reporte como: sales, purchase, stock, chart, table_summary.
  • Para ver el gráfico, seleccione el tipo de reporte chart.
  • Para ver la tabla, seleccione el tipo de reporte table_summary.
  • Escriba instrucciones claras y significativas.
Ejemplo de prompt:

Generate a sales and stock summary report with table format for the last 30 days.
